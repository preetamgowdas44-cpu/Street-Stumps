# 🏏 Street Stumps

**A simple and interactive cricket scoring web application.**

Street Stumps makes it easy to manage cricket matches, track scores, and view match statistics through a clean, user-friendly interface.

## 🌐 Live Demo

[**Play Street Stumps**](https://cricket-score-counting.netlify.app/)

## ✨ Features

- **Match Setup** – Configure matches and manage team details.
- **Toss Management** – Record the toss result and decision.
- **Live Scoreboard** – Track runs, wickets, overs, and current scores.
- **Scoring Controls** – Record runs, extras, and wickets.
- **Undo Option** – Correct the previous scoring action.
- **Over Timeline** – View ball-by-ball progress.
- **Full Scorecard** – View batting and bowling statistics.
- **Match History** – Access previously completed matches.
- **PWA Support** – Install the application on supported devices.
- **Offline Support** – Access supported app features without an internet connection.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Progressive Web App (PWA)
- Service Workers

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/preetamgowdas44-cpu/Street-Stumps.git
   ```

2. Open the project folder.
3. Run the application using a local development server.
4. Open the local URL in your browser.
